✅ Administrador de Tareas
Esta aplicación sencilla forma parte de los ejercicios prácticos para aprender los fundamentos de Jetpack Compose. En este proyecto, se crea una pantalla que se muestra cuando el usuario ha completado todas sus tareas del día. La interfaz presenta una imagen representativa y dos mensajes de texto que felicitan al usuario por su logro.​

Durante el desarrollo, se aplican conceptos clave de Compose, como:

Uso de Column para organizar los elementos verticalmente.

Aplicación de modificadores (Modifier) para centrar el contenido en la pantalla.

Estilización de texto con propiedades como fontWeight y fontSize.

Gestión de espaciado mediante padding.​

Este ejercicio refuerza la comprensión de cómo estructurar y estilizar componentes en Compose, enfocándose en la disposición y presentación de elementos visuales y textuales.
